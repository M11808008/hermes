官方 / 一手來源查核

### 1. Tencent 官方新聞稿確認 Hy3 發布與 agent/productivity 定位

Tencent 2026-07-06 官方新聞稿標題為「Tencent Hunyuan Officially Releases Hy3, Advancing Agent Capabilities and Deeper Product Integration」。其中確認：

  • Hy3 官方發布，較 preview 版本提升穩定性與成本效率。
  • Hy3 已整合進 Tencent 產品與服務，包括 WorkBuddy / CodeBuddy、Yuanbao、Marvis、ima 等。
  • API 已在 Tencent Cloud TokenHub 提供，並將逐步整合至全球第三方開發者平台。
  • 模型是混合 fast-and-slow thinking 的 MoE 架構。
  • 295B total parameters，21B active parameters。
  • 支援 256K context。

### 2. GitHub / Hugging Face 確認開放模型與規格

### 3. 免費 API：官方模型是真的，但「免費」要看第三方平台條款

  • OpenRouter 有 `tencent/hy3:free` 頁面，頁面顯示 pricing 為 Free、context 約 262K，並註明 free endpoints 有 rate limits。
  • SiliconFlow 的 Hy3 API guide 寫明：Hy3 在 SiliconFlow 以 `tencent/Hy3` 提供 OpenAI-compatible LLM API，且「上線後前兩週」有 free API access。
  • Tencent 官方新聞稿說 API 在 Tencent Cloud TokenHub 與第三方平台整合，但本文擷取到的官方新聞稿沒有說「永久免費 API」。

因此，Reel 的「free API / AI agents free」應改寫為：**Hy3 可透過部分第三方平台免費或限時免費測試，適合原型與評估；正式長期使用仍要看 OpenRouter、SiliconFlow、Tencent Cloud 或其他供應商當下價格、rate limit 與服務條款。**

  • 把「免費 endpoint」當成探索期，而非正式 production baseline。

風險與提醒

  • 「AI agents free」是行銷標題，不代表 agent 工作流沒有成本；推理 token、rate limit、排隊、失敗重試與工具執行都會形成成本。
  • OpenRouter `:free` endpoint 可能有流量限制、可用性變動或下架風險。
  • SiliconFlow 的免費敘述是「first two weeks after launch」，不是永久免費。
  • 295B MoE 模型雖然 21B active，但完整部署仍需要高階 GPU/推理服務；不要把「open weight」等同「可在個人電腦輕鬆免費跑」。
  • Claude Code / Agent OS guide 是留言導流內容，未公開取得，因此本文不保存其步驟，也不保證可用性。
  • 使用中國模型與平台時，企業資料要評估資料落地、合規、隱私、供應商與跨境資料風險。
