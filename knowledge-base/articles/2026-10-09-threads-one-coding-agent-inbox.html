Threads｜One：把多個 Coding Agent 的等待、回覆與完成通知收進同一個 Inbox

一句話摘要

One 解決的是「Agent 會跑，但人不在終端機前」的協作斷點：讓 Claude Code、Codex、OpenCode 等既有 Agent 的提問與成果集中到一個可回覆的 Inbox，使用者可在 Mac、iPhone 或遠端伺服器情境中維持工作流前進。

官方可確認的能力

One 官方網站將它定位為既有 coding agents 之上的管理層，確認內容包括：

  • 支援／相容清單含 Claude Code、Codex、OpenCode、Pi、Omp、Amp 與 Grok。
  • Mac 開啟後可自動找出既有 Agent；不以「新的程式碼模型」自居。
  • Inbox 集中各 Agent 的問題與完成工作，可直接給出選項式回覆。
  • Toolbar 用顏色呈現 Agent 狀態：工作中、需要使用者、已完成。
  • Router 可連按兩次 Option，再以語音或文字交辦；One 會把工作送到對應 Agent 或開啟新的 Agent。
  • iPhone 在 Agent 提問或完成時推送通知，並能從同一 Inbox 回覆。
  • Linux／VPS 可透過一條連接指令加入同一 Inbox；官方稱此連線端對端加密。
  • 支援 macOS 13 以上，Apple silicon 與 Intel 皆可使用。

什麼情況特別有價值

  • 平行執行多個任務：前端、後端、測試與 code review 同時交給不同 Agent 時，可避免遺漏某個「等待你回答」的終端機。
  • 遠端開發：Agent 跑在 VPS、家中主機或 Linux server，而你暫時離開電腦時，仍能從手機處理澄清問題。
  • 需要人類決策的長任務：例如 Agent 遇到架構選擇、權限確認、測試失敗或 pull request review，不必等你回到原本那個 terminal 視窗。

價格與貼文資訊的差異

擷取時官方定價頁顯示：

  • Pro：3 日免費試用（需要信用卡），其後年繳 US$119.88，頁面換算每月 US$9.99；包含模型費與無限使用。
  • Lifetime：限量階段價 US$229 一次性，需自備 API key，含更新；官方說明可在 Mac 的 Settings 於 3 日內申請全額退款。

Threads 貼文提到「每天 25 次 AI 請求的免費方案」，但此資訊沒有出現在本次官方定價頁。因此應以結帳頁與當下產品內方案為準，不能假設每日免費額度仍存在。

導入前的實務檢查

  • 不要將 One 視為取代 Claude Code 或 Codex 的模型；它是協作入口與路由／通知層。
  • 先確認它對本機 terminal、遠端 connector、語音與 iPhone 所要求的權限範圍。
  • Lifetime 方案需要自己的 API key；釐清哪些請求會走自己的帳單，哪些由既有 Agent 服務計費。
  • 遠端機器雖標示端對端加密，仍應檢視其連接器安裝命令、可存取範圍、撤銷方式與工作記錄處理。
  • 先以不含機密憑證的測試專案驗證通知、回覆、失敗復原與終止工作流。
