Threads｜Inkling 2 Mini：開放權重、循環架構與 32GB Mac 的限制

一句話摘要

Thinking Machines Lab 的 Inkling 2 Mini 確實是 2026 年 11 月 20 日發布的多模態開放權重模型；32GB Apple silicon 是官方列出的硬體選項，但不代表百萬 token 圖文情境在此記憶體容量下可順暢執行。

原帖與查核範圍

原帖提出 26.4B 總參數、3.4B 活躍參數、約 20GB、100 萬 token 上下文、DeepSWE v1.1 48.2% 和 Apache 2.0 商用等主張。查核日期 2026-11-23。頁面可見一則其他用戶散熱留言，未見可辨識的作者續文；登入介面及動態載入可能限制完整性。相關串文是推薦內容，不作作者續文。

官方身分、架構及授權

正式名稱 Inkling 2 Mini，提供者 Thinking Machines Lab, Inc.；不是其他公司相似命名的模型。官方模型卡指明文字及圖片輸入、文字輸出，最長 1M token。24 層中間 12 層共執行三次，共 48 次層應用；是共享權重而非 48 組獨立權重。稀疏 MoE 總 26.4B、每次 3.4B 活躍；考慮重複循環，官方稱每 token 約 5.4B 等效活躍參數，不能把 3.4B 當成整次運算成本。

官方模型卡標示 Apache 2.0；可依授權條款商用、修改和再散布，但須遵守保留授權及聲明等條件。模型卡另連 Model Acceptable Use Policy；其與 Apache 權利的具體法律關係應按原文及實際使用情境確認，不等同所有下游程式、資料和素材皆同授權。開放權重不等於訓練資料、完整訓練流程都已開源。

Hugging Face 官方倉庫為 thinkingmachines/Inkling-2-Mini，查核時 API 顯示公開且非 gated；實際檔案清單包含 safetensors 權重。未下載權重或執行模型。

基準與推論效能的界線

官方公告報告 DeepSWE v1.1 48.2%、Vals Index v2.2 46.5%，並稱在其比較中領先總參少於 100B 的開放權重模型。這是發布者在所列基準與比較對象上的結果，非所有程式任務的普遍冠軍。公告圖也明說各模型評估設定不同；54.4 tokens/s 是 614 GB/s、BF16、batch 1 等假設下的理論解碼上限，並非 32GB Mac 實測速度。

32GB Mac、量化和百萬上下文

官方模型卡說單個混合精度檢查點約 20GB，列出 32GB 以上 Apple silicon，軟體包括 Ollama、Exo Labs，並提及第三方 GGUF 量化版本。原版多數權重訓練及部署使用 NVFP4，最後 4 層 MXFP8，與事後轉量化版本不同；各版本的大小、品質、格式支援及圖像能力須逐一確認。公告實際飛航示範使用 M5 Pro、48GB MacBook Pro，而非 32GB 百萬 token 實測。

20GB 是模型檢查點／官方所述佔用約數，不是完整長上下文記憶體需求；系統、執行框架、暫存、KV cache、影像處理及並發都需額外資源。32GB 統一記憶體還須與系統共享；可載入短上下文並不保證可跑滿 1M，長提示也可能造成緩慢、換頁或記憶體不足。KV cache 隨實作、精度與模型注意力配置變化，不能僅從權重大小推算精確上限。建議未來依實際版本從短上下文開始，監看記憶體壓力與速度；本次沒有安裝、下載模型或進行效能測試。
