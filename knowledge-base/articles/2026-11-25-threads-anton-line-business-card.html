LINE 官方：建立及分享是不同環節

LINE 官方將 Flex Message 描述為以 JSON 定義的互動式版面，可有文字、圖片和按鈕；不同裝置、LINE 版本與字型可能呈現不同。官方 Flex Message Simulator 提供版型預設及電子名片教學，可預覽版面；官方教學說明使用模擬器可能要求登入。官方另提供名片示例 JSON；它不是作者的付費工具包。

一般帳號能否傳？不能把「Flex 必須用官方帳號傳」當成絕對規則。官方 LIFF 文件稱，開發者可啟用 shareTargetPicker，使用者選擇朋友、群組或聊天後，訊息會以使用者的身分顯示給收件者。這需要相應 LINE Login channel、LIFF 應用與啟用條件；不是說一般聊天輸入框可直接貼 JSON 發送，也不能證明本帖實作就是 LIFF。是否支援特定訊息類型與環境，須查 API 及實際配置。本次未登入或傳送測試。

官方帳號與計費

透過 Messaging API 由 LINE 官方帳號發送是另一條路。官方定價文件說明各地有免費及月費方案，各含不同免費訊息量，超額及附加費依方案；台灣實際金額未在本次查證，不套用該文件的日本示例。官方以接收人數計算：push、multicast、broadcast、narrowcast 計入方案訊息數；reply 不計入該數量。這些規則適用官方帳號 Messaging API，不應直接套到 LIFF 個人分享。費用與限制可能變動，使用前查 LINE 台灣官方現行方案。

安全與實作檢核

  • 名片只放願意公開的資訊；手機、Email、肖像、公司識別及客戶資料先取得授權，不放私人對話、憑證或 token。
  • 圖片和連結可能轉傳或長期公開；確認圖片主機、網址有效性、目的地與隱私政策，先使用虛構測試資料。
  • 檢視第三方工具及 AI 服務的資料處理、存取權限、保留與刪除政策；不把金鑰嵌入公開網頁或訊息。
  • 在模擬器及多裝置檢查排版、按鈕與替代文字；正式寄送、授權或付費前由本人確認。外觀相似不代表底層技術相同。
