Strata：用 12GB NVIDIA GPU 與 64GB RAM 跑 Qwen3.8-Flash-Next 的本機推理引擎

一句話摘要

Strata 是公開的本機推理引擎，目標是在 Windows 或 Linux 的 NVIDIA 遊戲電腦上執行 Qwen3.8-Flash-Next 125B MoE；它不是把 125B 全部塞進 12GB 顯存，而是把工作分散到 GPU、系統 RAM、CPU 和 SSD。

來源脈絡

Facebook 使用者陳盟升分享「12G 顯存＋64G 記憶體可跑 125B 本地模型」並連向 GitHub 專案 Niko1221/Strata。專案 README 在本次擷取時可直接讀取，並標示程式碼採 MIT License；但模型、模型壓縮版本與實驗性向量各有其上游授權，不能把程式碼的 MIT 授權延伸成模型或輸出內容都可任意商用。

官方 README 可確認的內容

  • 硬體前提：README 的安裝段落要求 NVIDIA RTX 30／40／50 系列、至少 12GB VRAM、依量化版本而定的系統 RAM、約 80GB 可用磁碟空間，以及 Windows 10/11 或 Linux。SSD 能縮短首次啟動時間。
  • 64GB RAM 的意義：它能容納 README 列出的四種原始模型量化大小；其中 IQ3_S 約需 54.8GB RAM＋VRAM，且需幾乎不開其他大型程式。48GB RAM 時，README 建議只選 Q2_0 或 IQ2_XS。
  • 架構：專案解釋模型有 24,576 個 experts，每個 token 只使用其中 10 個；GPU 保留常用 experts，RAM 保存全部 experts，CPU 與 GPU 並行處理，SSD 保存大型查表資料。這是降低 GPU 記憶體需求的關鍵，但也表示 RAM、CPU、PCIe、SSD 與背景程式都會影響體驗。
  • 本機 API：服務預設在 http://127.0.0.1:8080，可提供 OpenAI 相容的 /v1 端點與 Anthropic 相容的 /v1/messages 端點。README 同時說明，若以 --host 0.0.0.0 開放給其他裝置，必須設定 API key；不應把未加防護的本機推理服務暴露到網際網路。
  • 單一請求：README 明示目前一次處理一個 request，因此較適合個人或低併發工作流，不是多使用者高吞吐服務的直接替代品。

速度數字要怎麼讀

專案的數字是 RTX 5070（12GB）、Ryzen 5 7600、64GB RAM 上的作者實測：Q2_0 在短對話為 90 tokens/s、128K context 為 67 tokens/s；IQ2_XS 是 74／60 tokens/s；IQ3_XXS 是 62／46 tokens/s；IQ3_S 是 52／41 tokens/s；Coder IQ1_M 是 51／44 tokens/s。長 prompt 讀取則約 1,070–1,310 tokens/s。

所以 Facebook 所說「預加載破千」和「長上下文每秒 40–60 token」可對應到 README 的特定機器與量化設定，但不是 12GB GPU 的通用保證。不同顯卡、驅動、RAM 頻寬、SSD、context 長度、量化、溫度與背景負載都會改變結果。README 也提供 calibrate 流程，且將多 GPU layer split 標為 experimental。

模型與授權邊界

Strata 的程式碼採 MIT License；README 明確指出 Qwen3.8-Flash-Next、ISTA-DASLab 的 Coder 壓縮版與 UkisAI Swift 1.5 的模型檔，均應遵守各自上游授權。另有 ggml、字型與實驗性 speed projection vector 的不同授權。採用前應逐一查看實際下載模型的授權、使用限制、資料處理與輸出責任。

導入檢核表

  • 先確認 GPU 為支援的 NVIDIA RTX 且有至少 12GB VRAM；系統 RAM 與可用 SSD 空間比「模型參數量」更直接影響是否可開機。
  • 先用 IQ2_XS 或較小量化版本做低風險測試，關閉記憶體占用高的瀏覽器、IDE 與同步軟體。
  • 僅以 localhost 使用 API；若需區網存取，使用強密鑰、受信任網段與防火牆，不要把 0.0.0.0 直接暴露到公網。
  • 將長 context、影像輸入與 coding agent 視為額外負載；以自己的 prompt、context 長度與任務成功率測量，不只看 tokens/s。
  • 對模型授權、第三方程式碼、敏感資料與生成結果另行檢查，不把 GitHub repo 的 MIT License 當成完整授權答案。
