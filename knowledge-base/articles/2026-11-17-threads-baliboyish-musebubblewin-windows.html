一句話摘要

MuseBubbleWin 是獨立社群開發的 Windows WebView2 懸浮視窗，並非 Muse 官方程式；開源授權不等於服務免費或程式安全已獲驗證。

2026-11-17 查核時，專案 README 指其為獨立非官方社群專案，未獲 Meta 或 Muse 背書；功能包括可拖曳懸浮泡泡、嵌入聊天、置頂、外觀切換、系統匣與附件選擇器。原貼連到 v0.7.0，GitHub latest 當時為 v0.7.2；兩者不可混同。以下原始碼觀察固定 main commit dc16baa9c00917fc82f9ffb2ec974e67c0a06ace，不代表任何下載檔與其完全一致。

安全、隱私與使用條件

README 列 Windows 10／11 x64、.NET Framework 4.8 或更新版、Edge WebView2 Runtime、網路及 Muse 帳號；原始碼建置另列 .NET 10 SDK。程式載入 https://muse.ai/，不是離線或本機模型。README 說明登入狀態及 WebView2 profile 留於 %APPDATA%/MuseBubbleWin/WebView2Data/，設定也在 AppData；勿把這些資料夾、cookies 或診斷紀錄分享出去。

固定版原始碼可見 WebView2、注入頁面樣式腳本、彈出視窗及透過 Chrome DevTools Protocol 的主機附件選擇器；選取附件可能交給網頁服務處理。這些是有限靜態觀察，並非完整安全審計或惡意程式排除，也未驗證登入、檔案上傳或網路流向。請先獨立審閱程式、發行來源、依賴與簽章，避免輸入敏感資料；不要把原貼留言中第三方 Telegram 機器人視為官方兌換管道，也不要交出帳密、cookie 或驗證碼。
