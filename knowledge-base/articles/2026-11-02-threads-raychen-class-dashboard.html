班級儀表板：任務魚、教室時鐘與本機資料的安全界線

班級個資與授權

  • 座號、打卡、個人點數、任務與聯絡簿內容若能結合班級識別學生，仍可能涉及個資；投影畫面也可能暴露表現與進度。先採假資料測試，避免輸入姓名、聯絡方式、健康或敏感紀錄，依學校規範評估後使用。
  • 共用裝置的瀏覽器使用者可能看到或更改資料；不要把教師控制台視為已驗證的身分驗證或權限隔離。備份 JSON 非加密保險箱，避免公開分享，採校方核准的加密儲存、最小權限及刪除規則。
  • 每次更新前先備份並驗證還原可用性，但勿在公開或共用裝置以真實學生資料測試。自動更新的遠端網頁程式可能改變行為，應定期重查。
