Threads｜Scenario Kinetic Film：把動態字卡宣傳片做成可檢查的 Claude Skill

一句話摘要

Scenario 的 Kinetic Film 把高節奏的產品／遊戲宣傳短片，拆成「音樂節拍表 → 程式化動畫 → 渲染與逐格 QA」；Claude 負責依 brief 編排流程，Scenario MCP 則用於音樂、音效與關鍵視覺素材，而不是神奇地自動完成一切。

社群貼文重點

Threads 的 AI Threads 分享者 @ethansavemoneydairy 將這套流程描述為把 Higgsfield Katana 類型的動態設計工作拆成可下載的 Claude Skill：輸入產品、遊戲或品牌的幾行 brief 後，由 agent 推進影片製作。

貼文列出四個方向：腳本與節奏規劃、Scenario MCP 製作音樂與音效、code-driven motion，以及逐格品質檢查。貼文本身的「R.I.P. Higgsfield Katana」是吸睛的修辭，並不是 Higgsfield 服務已終止或被 Scenario 正式替代的可驗證公告。

官方查核：Kinetic Film 實際是什麼

Scenario 官方 Exploration 頁面明確表示：一支影片由單一網頁組成，以程式逐格渲染；其展示片長 51.8 秒、3,108 格，搭配 174 BPM 音軌。官方稱此流程不使用一般時間軸或「生成式 motion」，每一格由程式碼計算；Scenario 用於生成程式本身無法產生的音樂、音效，以及需要時的圖片素材。

官方公開 ZIP 內含 `SKILL.md`、JavaScript 動畫 engine、範例 spec、Python／Node 渲染與品質檢查 scripts，以及字型授權檔。這證實它是一個可檢視、可修改的工作流包，而非只有展示頁的宣稱。

四個可驗證階段

### 1. Brief 變成 beat sheet

Skill 先把時長、BPM、短句、每段場景 block、drop 與收尾定義成 beat grid。規則是每個 beat 或半拍承載一個想法，讓文字、切鏡與轉場落在節奏點上。這是「影片看起來有節奏」的核心，不是單靠 prompt 的形容詞。

### 2. Scenario MCP 製作聲音與視覺素材

官方文件說明，Scenario MCP 可用於指定節奏的配樂、一次性音效組，以及產品圖、角色或 key art。流程先要求 agent `recommend` 合適模型、讀取 schema、以 `dry_run` 估價，向使用者報價並取得同意後才正式執行與下載素材。

因此，這不是免費也不是無需確認的流程；連接 Scenario 帳戶、選擇 team／project、素材生成成本與使用權，均需在實作前確認。

### 3. Code-driven motion

動畫主體以 JavaScript 的 `spec.js` 場景描述和 engine 組成。每個畫面是時間 `t` 的可重現函數，避免 `Math.random`、系統日期或依前一格累積的狀態，這樣渲染器才能做子格取樣產生真正的 motion blur。

可調整的不是只有文案，還包括 palette、logo、字幕、鏡頭移動、whip pan、文字飛越、色彩切換與音效 cue。好處是可版本控制、可重製；代價是需要懂得讀／改程式與處理渲染環境。

### 4. 預覽、渲染與可量測 QA

Skill 要求先產 1080p 檢查版，再產 4K master，並使用 `finish.py` 檢查動態程度、過長靜止畫面、切鏡密度、檔案大小與手機／QuickTime 解碼相容性。官方示範設定包括：end card 前靜止格不超過 40%、不超過 0.6 秒的長停留、每 10 秒約 8.5 個硬切。

這是最有價值的設計：把「看起來動感」轉成可失敗、可修正的品質門檻，而非只依主觀感受交片。

本機執行條件與邊界

官方 Skill 的前置需求包括 Node.js 18+、Playwright／Chromium、ffmpeg／ffprobe、Python 3、NumPy 與 OpenCV；它不是只安裝 Claude Skill 就可直接在任何裝置輸出影片。4K 渲染亦會需要足夠的儲存空間、時間與硬體資源。

若要把真實客戶產品、未公開遊戲、品牌資產或人像交給 MCP／雲端生成服務，應先確認授權、帳戶方案、資料處理規則與可公開範圍；不要因為動畫引擎在本機，就假設所有輸入與生成資產都不會離開本機。

對創作者的實用取捨

  • 想快速產出節奏型 launch film：這是一個值得測試的可編輯起點。
  • 想完全不碰程式、環境或付費素材生成：它不會是零摩擦的一鍵方案。
  • 有既有品牌規範：先準備短句、字型授權、色票、logo、產品截圖與可驗證數據，再寫 brief。
  • 要公開商用：把音樂、音效、圖片、字型、模型生成素材的授權與來源一併保存在專案交付物中。
