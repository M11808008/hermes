Oracle Cloud 交給 Agent 部署：SSH、DNS 授權與免費實例回收

社群案例，不是本次實測

作者自述申請 Oracle Cloud 免費實例後，為避免閒置收回，把 SSH 金鑰交給 AI Agent，安裝 Nginx、PostgreSQL 等環境；又稱 Agent 修改 Cloudflare DNS、用 rsync 上傳程式碼並生成部署腳本，之後一條指令即可部署。速度和成功都是作者單次個案，並非獨立測試，也不等於生產環境安全、長期穩定或與 Vercel 完全等價。

留言有人說設定 ssh config 即可，不必特別交出金鑰；作者在回覆中承認標題聳動（https://www.threads.com/@onlinemad945/post/DgO5JVwm6lC ）。他另稱自己嘗試一個月後某天才建成 instance（https://www.threads.com/@onlinemad945/post/DgO5Y5qm0Rl ），屬個人經驗，不保證申請資格或容量。

Oracle 官方規則（2026-11-27 查核）

Oracle 文件說 Always Free 閒置運算實例「可能」被回收：在 7 天期間，同時符合 CPU 使用率第 95 百分位低於 20%、網路使用率低於 20%，以及 A1 機型記憶體使用率低於 20% 的條件。記憶體條件僅適用 A1；並非只看登入次數，也不是一閒置就必然回收。安裝軟體或偶爾 SSH 登入不保證避免回收。不要用無意義負載假定能確保持續使用；建立獨立備份並測試還原。

文件稱 AMD Micro 最多兩台；A1 的每月免費用量為 1,500 OCPU 小時及 9,000 GB 小時，Always Free tenancy 相當於合計 2 OCPU／12 GB。Free Trial 有期限，與 Always Free 不同；額度、容量、區域、帳號類型及超額計費要核對當前條款。容量不足可能造成建立失敗，不代表作者的等待時間適用所有人。付費升級及超額使用可能產生費用。

權限與安全邊界

  • SSH config 只是連線設定，不是安全隔離：若 Agent 能呼叫 SSH，仍可能使用本機金鑰或 agent 的簽章能力執行遠端帳號可做的操作；有檔案讀取權時還可能讀取可存取的私鑰。不要把私鑰貼進聊天或提交版本庫。
  • 優先使用獨立部署身分與專用金鑰、受限帳號及目錄，限制來源、命令和必要權限；檢查 sudo、轉送及 shell 權限，敏感操作由人審核。受限制金鑰和伺服器的實際政策需測試，不能假設 ssh config 自動提供限制。驗證主機金鑰、保護私鑰、保留稽核紀錄，備妥撤銷與輪替方案。
  • Cloudflare 建議用可限資源及權限的 API token。DNS 編輯權是建立、讀取、更新、刪除及列出等權限，不是只能改一筆紀錄；按需求限特定 zone，設有效期限及適用 IP 條件，勿提供全域 API key 或不必要權限。不同 API 可能還需額外唯讀權限，應依實際端點查核。洩漏時立即撤銷並檢查 DNS 紀錄及稽核日誌。
  • Agent 讀取外部頁面或執行未審核腳本有提示注入與憑證外洩風險。先讓人審核部署差異、DNS 變更與刪除動作，隔離祕密；備份並確認復原。不保證任何單一措施能完全防護。

Oracle 文件 2026-11-28 查核：A1 Flex 的每月前 1,500 OCPU 小時與 9,000 GB 小時免費；Always Free tenancy 文件換算為總計 2 OCPU／12 GB，不應沿用舊文章常見的 4／24 作現行保證。AMD E2 Micro 最多兩台，實際可建組合受開機磁碟等限制。200 GB 是開機與區塊磁碟共用總額，不是每台另有 200 GB；另有五份磁碟備份、合計 20 GB 物件與封存儲存及每月 10 TB 出站資料額度，適用範圍以官方文件為準。上述作者規格為自述，未驗證其機型或帳單。

Always Free 與最多 30 天、300 美元試用額度不同。官方提醒試用結束前 A1 合計不可超過 2 OCPU／12 GB，否則既有 A1 實例會停用並於 30 天後刪除，除非升級。計算實例須位於 home region；容量不足可等候或在同區其他可用性網域嘗試，並不保證成功。官方稱升級後限額內 Always Free 資源仍免費、超額使用收費；升級並不保證容量或免回收，其他付費服務、超額、跨區磁碟及第三方模型 API 都可能有費用。注意預算警示不等於支出硬上限。

可考慮小型聊天機器人、靜態網站、私人 VPN、學習環境或輕量遊戲伺服器；Arm 相容性、影音轉碼效能、流量和授權需個別確認。優先安全更新、SSH 金鑰及最小權限、限制入站來源和管理介面、啟用驗證與 HTTPS；獨立加密備份並測試還原，監控使用量與費用。VPN 使用須遵守目的服務條款及法律，不保證地區資格。無意義製造負載不保證避免回收。
