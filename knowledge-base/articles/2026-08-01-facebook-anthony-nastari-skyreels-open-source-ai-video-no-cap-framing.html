官方查核：SkyReels / Skywork AI 實際提供什麼？

### 1. SkyReels V2：開放 repo / 權重，主打 infinite-length film generative model

SkyworkAI/SkyReels-V2 GitHub README 標題為 “SkyReels V2: Infinite-Length Film Generative Model”。README 說明此 repo 提供 infinite-length film generative models 的 model weights 與 inference code，並稱其採 AutoRegressive Diffusion-Forcing architecture。

可核實能力：

  • V2 有 Hugging Face / ModelScope 模型集合。
  • 模型表列出 Text-to-Video、Image-to-Video 與 Diffusion Forcing 相關模型。
  • 720P 模型包含 SkyReels-V2-DF-14B-720P 與 SkyReels-V2-I2V-14B-720P；README 說前者 facilitates infinite-length autoregressive video generation，後者聚焦 Image2Video synthesis。
  • README 提供本機 inference 範例與長影片 generation 參數，例如 10 秒影片的同步/非同步範例、video extension 與 start/end frame control。

官方來源：

  • https://github.com/SkyworkAI/SkyReels-V2
  • https://huggingface.co/collections/Skywork/skyreels-v2-6801b1b93df627d441d0d0d9

### 2. SkyReels V3：多模態 in-context learning、R2V / V2V / A2V

SkyworkAI/SkyReels-V3 GitHub README 說明 V3 是 flagship video generation model，建立在 unified multimodal in-context learning framework 上，原生支援多種生成能力。

README / Hugging Face 模型卡可見：

  • Reference to Video：SkyReels-V3-R2V-14B，14B-720P。
  • Video Extension：SkyReels-V3-V2V-14B，14B-720P。
  • Talking Avatar：SkyReels-V3-A2V-19B，19B-720P。
  • Talking Avatar 以一張圖片加音訊生成影片，說明中提到 720p、24 fps、lip sync、多語言唇形對齊與 long-form video generation。

這能對應貼文裡的 text/image generation、camera control、lip-synced voices 等方向，但「同一工具內加音樂/音效」比較像 SkyReels 網站產品層功能，未必是每個開源模型本身的能力。

官方來源：

  • https://github.com/SkyworkAI/SkyReels-V3
  • https://huggingface.co/Skywork/SkyReels-V3-R2V-14B
  • https://huggingface.co/Skywork/SkyReels-V3-A2V-19B

### 3. SkyReels 官網：有 Creative Studio / API Platform，但未登入頁無法直接驗證額度

SkyReels 官網公開頁可進入：

  • https://www.skyreels.ai/home

但未登入公開頁只渲染基本導航，沒有直接展示「free website version」的額度、duration cap 或 usage cap。因此本文把「免費網站版、無使用上限」保留為 Reel 文案聲明，而不是已由官網驗證的條款。

### 4. 授權：開源/開放權重不等於 MIT / Apache

GitHub API 顯示 SkyworkAI/SkyReels-V2、SkyReels-V3、SkyReels-A2 的 license 為 `Other / NOASSERTION`；Hugging Face 模型卡也顯示 `license_name: skywork-license`。repo 根目錄沒有可用 `LICENSE` raw 檔可直接查閱。

因此不能把「open source」簡化成「可任意商用、可無限制再散布」。若要商用、部署 SaaS、訓練衍生模型或處理客戶素材，需要讀完整模型卡與 Skywork license 條款。

如何務實使用這則資訊

  • **本機/雲端實驗**：先從 Hugging Face 模型卡與 GitHub README 跑最小 demo，確認 VRAM、推論時間、解析度與輸出品質。
  • **長影片/分鏡實驗**：用 V2 Diffusion Forcing / video extension 做段落式生成，不要期待一次 prompt 就穩定產出完整商業影片。
  • **人物/角色影片**：用 V3 R2V / A2V 做 reference-to-video 或 talking avatar，但要測試身份一致性、唇形同步與語言表現。
  • **產品化前檢查授權**：確認 skywork-license 是否允許商用、再訓練、API 包裝、模型託管或生成內容商用。
  • **與 Veo 3 / Kling 的比較**：把 SkyReels 視為可控、可本機化、可研究的替代路線；不要直接等同於付費商用平台的 SLA、易用性、審核、素材庫、音訊整合與穩定度。

風險與限制

  • 「no duration cap / no usage cap」是社群貼文 framing；官方 repo 可支撐「infinite-length / long video generation」方向，但實際長度仍受 GPU、記憶體、推論時間、參數與模型限制。
  • 「free website version」未能在未登入 SkyReels 官網公開頁直接驗證；網站額度、排隊、輸出解析度、商用條款可能變動。
  • Hugging Face 可下載不代表無成本：14B / 19B / 720P 影片模型需要高 VRAM、多 GPU或雲端成本。
  • 開源/開放權重授權是 skywork-license / Other，不是 MIT 或 Apache；商用前必須讀 license。
  • AI 影片可能出現人物身份漂移、手部/物理錯誤、鏡頭連貫性不足、唇形不同步、音訊對不上、浮水印或審核限制。
  • 使用人物照片、聲音、音樂、商標與影像素材時，仍需取得授權並清楚標示 AI 生成/編輯。
