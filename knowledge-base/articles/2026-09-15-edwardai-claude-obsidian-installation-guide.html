EdwardAI｜Claude × Obsidian 第二大腦安裝頁：開源 claude-obsidian 的安全導入與正確指令

一句話摘要

這個教學頁把 claude-obsidian 包裝為「兩分鐘把 Obsidian 升級成 AI 第二大腦」：丟入來源後，由 Claude 讀取、建立連結與歸檔。核心概念可行，但真正可靠的導入不該直接讓 agent 對既有筆記庫任意寫入，而要先建立或採用一個界線清楚、可備份、可審閱的 vault。

頁面主張與展示流程

EdwardAI 頁面以粵語說明：

  • 使用 Claude Code 作為 AI 層、Obsidian 作為知識庫介面。
  • 資料放進去後，AI 可讀取、抽重點、建立連結與歸檔，讓 Graph 隨時間累積。
  • 提供 `/wiki`、`/save`、`/autoresearch`、`/canvas` 四項常用指令的概念說明。
  • 頁面展示的快速步驟是 clone `AgriciDaniel/claude-obsidian`、執行 setup script、用 Obsidian 開啟資料夾，再從 Claude Code 啟動。

它把複雜系統講得很容易開始，適合作為概念導覽；但安裝指令與權限邊界需要回到專案 README 查核。

專案目前可確認的定位

`AgriciDaniel/claude-obsidian` 是 MIT 開源專案，GitHub 頁面目前顯示約 14.9k stars、v2.2.0、282 commits。它宣稱是 local-first 的知識系統：來源、Markdown、JSON 與原始檔留在使用者自己的 vault，而不是藏在外掛快取或雲端資料庫。

README 強調的工作循環是：

  • 保留來源與來源脈絡。
  • 對重要主張保留證據、時效性、矛盾與信心標記。
  • 建立連結頁面、索引、Maps of Content 與 Obsidian Canvas。
  • 重新查詢、研究、lint 與整理既有知識，而非每次從零開始。

專案並提供多個技能，例如 `wiki`、`save`、`wiki-ingest`、`wiki-query`、`wiki-lint`、`autoresearch` 與 `canvas`；Claude Code 使用 namespaced 指令，例如 `/claude-obsidian:wiki`，而非頁面簡化示範中的裸 `/wiki`。

與原頁不同、較安全的安裝方式

專案目前 README 的安全導向是「產品 checkout 與使用者 vault 分開」：clone 的 repository 不是你的筆記庫。初始化指令會先產生 plan，讓使用者檢查後，帶著核准的 SHA-256 才真正 apply。

概念流程如下：

  • Clone 專案並保留作為工具／plugin 來源。
  • 在另一個明確路徑建立新的知識 vault，不要直接拿 clone 目錄當日常筆記庫。
  • 先執行 `init` 產生 JSON plan，審閱變更範圍。
  • 以 plan 回傳的 `approved_plan_sha256` 明確核准後才加上 `--apply`。
  • 用 Obsidian 開啟 vault，再從 vault 目錄啟動 Claude Code 與 plugin。
  • 先從 inbox 放入可公開或已授權的測試來源，驗證 ingest、query、save 與備份流程。

依 v2.2.0 README，新的 vault 可用 `python3 scripts/claude-obsidian.py init <VAULT-PATH>` 先預覽；Claude Code 從 vault 目錄用 `claude --plugin-dir <claude-obsidian-checkout>` 啟動，再以 `/claude-obsidian:wiki` 開始。若要導入既有 vault，請使用文件中非破壞性的 `adopt` 流程，而非直接套用初始化腳本。

權限與資料安全

  • 這類 agent 需要讀寫本機檔案；先備份 vault，並將機密、個資、課程名單與憑證放在隔離位置。
  • local-first 不代表模型不會出網：若啟用模型 API、網址抓取、`autoresearch`、embedding 或 reranking，仍要確認資料會送往哪個 provider，以及是否有明確 egress 同意。
  • README 也明確標示 URL／YouTube、OCR 等功能可能需要外部 runner；不要把「能自動研究」理解成無條件、無外部連線或無風險。
  • 先在獨立測試 vault 觀察 agent 的新增、改寫、來源引用與 Graph 連結品質，再決定是否採用到長期個人知識庫。

對欒帥的意義

AI 學習雷達本身已具備相近的穩定模式：保留 Markdown 來源、產生可讀網站、保存原始連結、查核再部署。claude-obsidian 值得參考的強項是把來源／主張證據、可復原交易、vault lock 與 lint 納入知識庫操作；若未來要建立私人研究 vault，可把它當成獨立沙盒，而不是直接取代已運作的公開知識庫流程。
