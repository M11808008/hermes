Threads｜Sill：將 Mac 視窗以私有連線帶到 iPhone、iPad 的輕量遠端桌面

一句話摘要

Sill 是一個免費、開源的 Apple 平台遠端視窗工具：Mac 端擷取單一視窗或完整桌面，以 HEVC 串流到 iPhone、iPad；行動端可用觸控、外接鍵盤、觸控板或 Apple Pencil 操作。它不是雲端代管的遠端桌面服務，而是裝置之間的直接連線設計；外出存取應優先走自己管理的 VPN，並將 Mac 的螢幕錄製與輔助使用權限視為高影響權限。

Threads 貼文可直接確認的內容

設計師勞哥於 2026-10-17 分享 Sill，擷取時顯示約 3,637 次瀏覽、88 個讚、9 則回覆與 11 次轉發。作者主張 Sill 體積僅約 3.3 MB、可達 120Hz，並以家中跑本地模型的 Mac 為例，說明可透過 VPN 從 iPhone Duo 遠端操作。

作者後續補充其技術理解：Sill 以 Swift 與 Apple 框架製作，使用 ScreenCaptureKit 擷取、HEVC 編碼，並在網路落後時丟棄舊影格以維持即時感。這些架構主張可由專案 README 與官網大致交叉確認；不過 3.3 MB、120Hz、個人裝置的實際流暢度與特定設備效果仍應視版本、網路、解析度與工作負載自行測試，不當作普遍性能保證。

官方與原始碼可確認的能力

Sill 官網與公開 GitHub repository 說明：

  • Sill 可在 iPhone、iPad 顯示 Mac 的指定視窗或完整桌面，支援觸控、觸控板、鍵盤與 Apple Pencil 操作。
  • Mac 端以 ScreenCaptureKit 擷取畫面，並利用 VideoToolbox 的硬體 HEVC 編碼器；當編碼或網路跟不上時，會丟棄影格而非累積佇列。
  • 裝置於同一網路、USB 線材或 Direct Wireless Connection 下連線；配對後，連線以 TLS 1.3 加密並固定於已配對裝置的金鑰。
  • 外出使用須開啟 Remote Access，並透過自己管理的 VPN（官網舉例 Tailscale）或路由器轉送連線。官方也說明裝置回到家中時會自動切回本地網路。
  • 需求為 Apple silicon Mac、macOS 14 以上，以及 iOS 17／iPadOS 17 以上。Mac 端需要螢幕錄製與輔助使用權限；macOS 15 以上還需要本地網路權限。行動端需要本地網路權限，掃描配對碼時才需要相機權限。
  • 專案公開採 Apache License 2.0；GitHub 原始碼、Mac 下載與 iOS／iPadOS App 都可取得。開源授權不等於免除使用者對本機資料、遠端網路與第三方內容的安全責任。

功能限制與需要留意的細節

官方 README 同時列出一些重要限制：一次顯示一個視窗或完整桌面、不傳送 Mac 音訊、剪貼簿僅處理文字且上限 256 KB，且 Mac 必須保持喚醒並已登入、Sill 正在運作。虛擬顯示器預設關閉，且因使用私有 macOS API，Mac 端透過官網下載而非 Mac App Store 發佈。

這些限制對「出門操作家中本地模型」尤其重要：推論本身仍在家中的 Mac 執行；Sill 傳送的是畫面、控制輸入與有限的文字剪貼簿，不是把模型或檔案自動搬到手機。延遲、頻寬、Mac 睡眠、VPN 路徑與應用程式本身的 GPU 負載，都會決定實際體驗。

安全導入檢核表

  • 先在同一個可信任的家庭／工作網路測試，確認視窗選擇、輸入、睡眠喚醒和網速表現。
  • 僅配對自己管理的 iPhone、iPad；定期在 Sill 的裝置清單移除不再使用的裝置。不要為方便而關閉 Require pairing。
  • 對外存取優先使用已啟用多因素驗證、裝置存取控管的私人 VPN；除非具備網路隔離、更新與監控能力，避免直接公開路由器連接埠。
  • 將螢幕錄製與輔助使用權限視為高敏感權限：Sill 能看見被串流的畫面，且輔助使用權限可協助點擊、捲動與輸入。不要在共享 Mac 或不可信任的行動裝置上寬鬆授權。
  • 先用沒有機敏資料的測試帳號／視窗試跑；處理密碼、金融、內部系統或個資前，檢查手機鎖定、VPN、配對裝置與剪貼簿設定。
  • 更新到目前版本。專案 README 特別提醒，舊版 Sill for Mac 0.3.1 及更早版本在部分本地連線情境沒有加密與配對保護；不應部署舊版。

為什麼值得收進 AI 學習雷達

對在 Mac 上跑本地模型、IDE、瀏覽器自動化或工作流的人，Sill 提供的不是另一個「手機上的 AI」，而是一條偏本地優先的操作通道：將算力與資料留在自己的 Mac，行動端成為受配對與加密約束的顯示／輸入端。真正的關鍵不在宣稱的幀率，而在是否妥善控制配對、VPN、Mac 權限與機密畫面。
