AI Engineering from Scratch：把「會用 AI」補成「能造出 AI 系統」

一句話摘要

這是一套以「先自己做出來，再用成熟函式庫對照」為方法的免費開源 AI 工程課程；它不追求週末速成，而是帶學習者從數學與底層實作一路走到 LLM、MCP、Agent 與生產部署。

來源脈絡

Threads 貼文由「無聊就學AI Lab | Boring Traveler」分享，原文將它定位為適合會寫程式、希望把「會用 ChatGPT」提升到「能把系統做出來」的人所使用的長期自學地圖。

貼文提到約 20 個階段、500 多課，以及每一課都留下可再利用的提示詞、技能包、Agent 或 MCP 伺服器。貼文圖片與原始 GitHub README 可交叉確認這個專案的名稱、MIT 授權、20 phases 與完整課程方向。

課程重點

### 從底層基礎逐層往上

原始課程的架構從以下主題展開：

  • Setup and Tooling：開發環境與工具鏈
  • Math Foundations：線性代數、機率與數學直覺
  • ML Fundamentals：機器學習基礎
  • Deep Learning：神經網路與深度學習核心
  • Vision、Speech、NLP：視覺、語音與自然語言
  • Reinforcement Learning：強化學習
  • Transformers、Generative AI、從零實作 LLM
  • LLM Engineering 與 Multimodal AI
  • Tools and Protocols：工具呼叫與 Model Context Protocol（MCP）
  • Agent Engineering、自主系統、多 Agent 與群體
  • Infrastructure、Production、倫理安全與綜合專案

GitHub README 目前列出 20 個階段、523 節課，約 342 小時；Threads 貼文則以「500 多課」概括介紹。課程內容與統計可能隨專案更新，數字應以原始 repository 為準。

### 每課的實作循環

課程不是只讀概念或複製框架範例，而是反覆走過：

  • 讀懂問題與背景
  • 推導數學與核心概念
  • 不依賴大型框架，先手寫一個可理解的版本
  • 用 PyTorch、scikit-learn 等生產級函式庫重新實作
  • 留下提示詞、技能、Agent 或 MCP server 等可重用產物

這種安排的價值在於：使用框架時，不必把它當成黑盒子；學習者會知道 API 背後正在處理什麼。

為什麼值得收進 AI 學習雷達

這個專案特別適合作為「從工具使用者走向系統建造者」的課程索引：

  • 把數學、模型、工程、Agent 與部署串成同一條路徑。
  • 每一階段都有可以執行或保存的成果，不只留下閱讀筆記。
  • 內容同時涵蓋 Python、TypeScript、Rust 與 Julia，適合觀察不同語言在 AI 工程中的角色。
  • Agent 與 MCP 被放在完整工程脈絡中，而不是孤立的提示詞技巧。
  • MIT 授權、原始碼公開，方便自行閱讀、修改與建立學習分支。

適合怎麼開始

不建議直接從第一課一路硬啃。可以依目標選路：

  • 初學或環境未整理好：從 Phase 0 Setup and Tooling 開始。
  • 已會 Python、想補理論：先看 Math Foundations 與 ML Fundamentals。
  • 想做 LLM 應用：進入 Transformer、從零實作 LLM 與 LLM Engineering。
  • 想做 Agent：先理解 LLM 基礎，再進入 Tools and Protocols、MCP 與 Agent Engineering。
  • 想用編碼 Agent 做真實專案：使用 repository 提供的 Agent-Assisted Engineering learning path。

建議以「每週完成一個小階段、每課保留可執行產物」取代追求快速看完全部內容。
