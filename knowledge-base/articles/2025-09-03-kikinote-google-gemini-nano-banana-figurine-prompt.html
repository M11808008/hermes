KiKiNote｜Google Gemini Nano Banana 公仔生成教學：用照片做 1/7 寫實角色手辦

一句話摘要

這篇教學示範如何用 Google AI Studio / Gemini 的 Nano Banana 圖片生成模型，把上傳的人物或角色照片轉成寫實 1/7 比例 3D 公仔手辦；核心價值在於 prompt 已把比例、材質、桌面情境、燈光、ZBrush 建模背景與外盒包裝一次指定清楚。

操作流程

文章提供的基本流程如下：

  • 進入 Google AI Studio。
  • 選擇 Nano Banana 模型。
  • 點選加號，上傳圖片。
  • 輸入公仔生成 prompt。
  • 點選 Run 生成圖片。
  • 點選產生的 AI 圖片檢視。
  • 用右上角下載圖示保存結果。

中文 Prompt

請將圖片中的角色，製成一個寫實的 1/7 比例角色模型手辦，擺放在 Windows 電腦桌面上，搭配一個帶有 RGB 背光的機械電競鍵盤。手辦立於一個乾淨、無任何標誌或文字的圓形透明壓克力底座上。專業的攝影棚燈光突顯了雕刻的細節。背景的 Windows 螢幕上，顯示著同一款手辦正在 ZBrush 中建模的過程。在手辦旁邊，放置一個與公仔比例相符、印有該角色圖案的公仔外盒，包裝盒帶有圓角和透明的前視窗，裡面沒有公仔。

英文 Prompt

Create a realistic 1/7 scale character figurine based on the character in the image, placed on a Windows computer desk with a mechanical gaming keyboard featuring RGB backlighting. The figurine stands on a clean, round transparent acrylic base with no labels or text. Professional studio lighting highlights the sculpted details. On the Windows monitor in the background, display the ZBrush modeling process of the same figurine. Next to the figurine, place a proportionally scaled packaging box featuring the character’s artwork, with rounded corners and a transparent front window, shown empty without the figurine inside.

Prompt 拆解

這組 prompt 之所以容易產生「像商品照」的公仔效果，是因為它同時指定了多個可控維度：

  • 主體：根據圖片中的角色生成。
  • 比例：寫實 1/7 scale character figurine。
  • 場景：Windows 電腦桌面與 RGB 機械電競鍵盤。
  • 底座：乾淨、無文字、透明圓形壓克力底座。
  • 燈光：專業攝影棚燈光，用來凸顯雕刻細節。
  • 背景敘事：螢幕上顯示同一款手辦在 ZBrush 中建模。
  • 商品化元素：旁邊放一個與比例相符、印有角色圖案、圓角透明視窗、內部空盒的公仔外盒。

這很適合拿來教「好 prompt 不是形容詞堆疊，而是把構圖、材質、背景、用途與輸出限制講清楚」。

進階修改技巧

KiKiNote 也提醒，如果第一次生成後只有局部細節不滿意，可以繼續用中文要求 Gemini 修改，例如「我想要公仔高一點」、「外盒我要咖啡色」。重點是加上「其他地方不動」，讓模型把修改範圍限制在指定元素，避免整張圖被重新發散。

可用補充句型：

  • 只修改外盒顏色為咖啡色，其他地方不動。
  • 只讓公仔高度增加 10%，姿勢、表情、服裝與背景保持不變。
  • 只把底座改成透明藍色壓克力，其他地方不動。
  • 修正手部細節與臉部相似度，其他構圖不變。

保存判斷

這篇值得放進 AI 學習雷達，原因不只是「Gemini 公仔玩法」本身，而是它提供了一個容易引起學生興趣、又能拆解 prompt 結構的案例。對課程設計來說，可以先讓學員用自己的照片或角色圖生成公仔，再回頭分析 prompt 為什麼有效，進一步延伸到商品 mockup、角色 IP、社群素材與個人品牌視覺。
