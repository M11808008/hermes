Facebook｜YoJu Hsu 用 Claude 製作 Garmin「往下挖」錶面

一句話摘要

作者稱以 Claude 製作像素狗挖掘錶面，46 分鐘完成電腦模擬版，修改至第三版才裝進手錶；仍在測試，沒有下載連結。

作者的案例

「往下挖」讓像素小狗依走路距離往下挖，穿越八層，從現代表土到約三萬年前，靈感來自作者的台灣史前史專案。圖卡 1 至 5 依序展示目前錶面、距離挖掘概念、三次設計比較、作者列出的工具及排錯經驗。46 分鐘是作者單次經驗，不是其他人可重現的承諾；第三版實際品質、程式與硬體相容性未由本次實測。

圖卡 4 列出 Connect IQ SDK Manager、Java 17、開發者金鑰以及作者在 Mac 連接 Venu 3 使用的 OpenMTP。圖卡 5 提及 Java 空殼、裝置庫缺少型號、黑底看不到狗、Mac 傳檔及手機同步問題；這些是作者特定環境的經驗，不代表所有設備必須安裝相同工具或重新啟動必然有效。妥善離線備份並保護開發者私鑰，不放入公開倉庫。

Garmin 官方文件核對

  • 入門文件：SDK Manager 用於取得 SDK 與裝置庫；Monkey C VS Code 擴充文件列出 Oracle Java Runtime Environment 11 版以上，而非一律指定 17。實際要求依 SDK、工具和系統版本確認。
  • 上架文件：manifest 指定支援機型，VS Code 的 Monkey C 匯出命令建立包含支援產品二進位檔的 .iq 套件，送審期間不會出現在商店；獲核准後才上架。模擬器成功不保證實機、所有錶款或審核成功。
  • 官方商家申請：官方內建變現系統要求申請與審核，年度計畫費 100 美元且不退費；文件的支援清單列出美國、加拿大、澳洲、新加坡及多個歐洲地區，未列台灣，清單可能變動。這只限定 Garmin 內建變現系統，不能推論所有其他付費方式都不可用。依 SDK 開發者協議，不強制使用 Garmin Merchant Service；其他方案仍須遵守適用條款、資安與支付規定。
