登入、版本與費用

倉庫寫裝置碼登入，禁止讀取本地 auth.json 和要求密碼、一次性驗證碼；裝置碼及授權網址仍應核實來源、授權範圍與時效，勿替他人批准登入。原帖與技能寫 device-code；查核時 xAI 官方 Build 文件寫 device-auth，兩者相容性未驗證，不應盲目照貼。README 稱訂閱額度或付費 API key 可用，方案資格、區域、用量及額外計費會變。官方 Responses API X Search 標示每千筆抓取貼文 5 美元、每千個用戶檔案 10 美元，另計 token，重複抓取也計；這是 API 價格，不能直接當作訂閱版 CLI 單次費用。

傳輸與風險

搜尋需求與上下文會送往 Grok/xAI；返回的貼文及摘要可能交回 Muse，技能還建議有價值時儲存完整輸出至工作區。具體保留、訓練、地區與權限依帳號、產品及服務條款而異，勿輸入秘密、個資或敏感資料。技能以自然語言要求只讀、不發文，並非技術性的權限撤銷；Grok Build 是可使用終端和工具的代理，外部貼文可能含提示注入。官方有獨立的權限及沙箱機制，仍需最小權限、人工審核、限制網路與支出。僅檢查安裝腳本是否寫入家目錄不足以保證安全，且遠端最新版未固定可能變更。

能力驗證與限制

xAI 官方文件證實 API 的 X Search 支援關鍵字、語意、用戶搜尋與串文抓取；模型決定查詢，篩選與結果有範圍限制，不能保證完整回覆、引用或代表性，也可能產生錯誤，重要資訊需逐一查原帖。倉庫作者自述在自己環境完成測試，不能替代本次實測或保證目前帳號適用。Muse 官網未登入頁未提供可核實之社群搜尋範圍；未找到足夠官方證據證明「能廣泛搜尋所有公開 Meta 圖文」或「完全不能搜尋 X」等絕對說法，亦未登入操作驗證。回覆中另一個自稱 meta.ai 的帳號發言並非可獨立驗證的官方功能文件。
