第一方文件能確認什麼，不能確認什麼

Anthropic 的 Claude Code Overview 確認 Claude Code 是可讀取程式碼庫、編輯檔案、執行命令並整合開發工具的 agentic coding tool，也說明其可在終端機、IDE、桌面 app 與瀏覽器使用。這能確認 Claude Code 與專案／開發工作流是正式產品範圍的一部分。

但 Overview 並不是促銷或額度條款，不能證實本 Reel 的五項金額、每月配額、免費 code review 次數、期限或 Max／Pro 差異。Anthropic Help Center 的 API 說明亦將付費 Claude 訂閱與 API／Console 的帳務分開處理；因此即使某帳號曾收到 API credit，也不代表所有訂閱帳號都享有、或訂閱本身自動包含 API 用量。

為何應把它視為「待查核的促銷清單」

  • 金額與資格型優惠經常依帳號、方案、地區、受邀身分、首次啟用條件、合作計畫或活動批次而不同。
  • 「10/22 前」表明至少其中一項是限時資訊；社群影片的發布時間不等於可領取期限，更不代表現在仍有效。
  • 「API 額度」可能是 Console credit、試用額度、合作計畫資格或其他活動贈額；不可把它等同於訂閱聊天額度，也不可用來推估所有人的 API 帳單。
  • 任何要求首次建立專案、邀請朋友或進入特定連結的活動，都應先確認網址屬於 Anthropic 官方網域、沒有要求不必要的帳密或金鑰，並讀完適用條款。

實際檢查清單

  • 在已登入的 Claude 與 Anthropic Console 中查看方案、帳單、通知、credits／usage 與活動條款，不要依影片截圖判定資格。
  • 對每一項福利記下名稱、官方連結、可領取頁面、額度、貨幣、到期日、帳號條件與是否已兌換；活動若缺少可公開核對的條款，就標為「未驗證」。
  • API credit 只在 Console 的實際餘額或帳單顯示後才納入預算；不要因為社群聲稱的金額而假設免費或停止設置用量上限。
  • 建立 Claude Code Project、啟用 code review 或邀請他人前，先確認將存取哪些 repository、資料與權限；試用／贈額結束後也要檢查後續計費與取消方式。
  • 不要把登入憑證、API key、付款資訊或完整帳單截圖交給社群帳號或非官方表單。需要協助時優先使用 Anthropic 官方支援與產品內頁面。

為什麼值得收進 AI 學習雷達

這支影片的提醒價值在於：AI 訂閱的權益可能分散在產品、Console 與限時活動之中。然而最可靠的操作不是「照著按一輪」，而是把每個聲稱拆成可驗證的帳號資格、時間與條款，再依自己的使用量與風險決定是否啟用。特別是 API 額度與聊天訂閱帳務不同，應分開管理。
