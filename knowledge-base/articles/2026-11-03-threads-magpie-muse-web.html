Threads｜magpie-muse-web：以瀏覽器帳號連接 coding agent 的非官方外掛

一句話摘要

Magpie 的非官方第三方外掛 magpie-muse-web 宣稱以本機瀏覽器操作 muse.ai 網頁帳號，提供 Muse Spark 給 Codex、OpenCode 等 agent；不是官方 API，也不是原生工具呼叫。本文依貼文和專案 README 記錄，並未安裝、登入、送出請求或驗證效果。

貼文與查核邊界

廖北北分享了瀏覽器登入、多帳號排程與每週額度卡片，並指出工具呼叫以提示詞模擬、可能格式失敗，以及非官方外掛可能因網站改版失效。GitHub 專案 README 確實描述這些設計；這是專案作者的說明，不代表獨立測試成功，也不證明 Meta 或 Magpie 官方背書。GitHub 顯示公開、非 archived；LICENSE 包含 MIT 授權與上游 muse2api 授權聲明。查核版本 cf08724566477581bfae955058a181cc8a15ffea；GitHub API 對授權分類顯示 NOASSERTION。

可重用設定參考（僅文件摘錄）

先審查程式碼及服務條款並自行評估風險，不應在重要帳號或機密專案上直接嘗試。以下是 README 所述流程，不是已驗證的實作結果。

  • 需求：Magpie（作者稱曾於 0.1.1223 驗證）、Chrome／Edge／Chromium／Brave 之一，以及可連線 muse.ai 的網路；作者稱使用 Magpie 內建 Bun，無須另裝 Node 或 Python。無桌面 Linux 無法開登入視窗。
  • 文件安裝命令為 magpie plugin add github:JohnWangggg/magpie-muse-web；登入命令為 magpie plugin login muse-web。也可透過 Magpie 的外掛頁與帳號頁操作；多個帳號各自登入。登入後預設會發一條短測試訊息並留在對話紀錄中，15 分鐘內未完成登入則逾時。
  • 模型識別碼為 muse-web/muse-spark；文件列出的啟動命令分別為 magpie codex muse-web/muse-spark 與 magpie opencode muse-web/muse-spark。magpie provider test muse-web 會真的發出請求，不是離線檢查。作者未實測不經 Magpie 直接安裝到 OpenCode。
  • 每個帳號一次只處理一個請求，忙碌或用量耗盡回 429 交由 Magpie 調度；登入失效回 401。額度卡顯示週用量、重置時間等，讀數可能因閒置或預熱而不是即時。
  • 可選環境變數包括 MUSE_WEB_PROXY（代理或 direct）、MUSE_WEB_BROWSER（headless／hidden／show）、MUSE_WEB_CHROME（瀏覽器路徑）、MUSE_WEB_IDLE_MIN（閒置分鐘，預設 60）、MUSE_WEB_PREWARM（0 關閉預熱）、MUSE_WEB_VERIFY_LOGIN（0 不發登入測試）、MUSE_WEB_ENGINE_PORT（預設 18611）、MUSE_WEB_HOME（資料目錄）及 MUSE_WEB_ENGINE（外部引擎）。更動前請確認上游最新版。
  • 更新命令為 magpie plugin update；移除使用 magpie plugin rm 加上 magpie plugin list 顯示的名稱。README 明言移除外掛不會刪除引擎資料目錄，停用後仍需自行確認並安全處理殘留。

運作限制與安全

  • 引擎透過無頭瀏覽器將 Chat Completions 轉成網頁對話。工具清單被寫進提示詞；模型以 tool_call 程式碼區塊輸出，解析器再轉成 tool_calls。這是合成工具呼叫，非原生函式呼叫；格式不符或未呼叫工具時只會返回文字，不能假設工具可靠執行。
  • 僅文字輸入／輸出：圖片和檔案會替換成文字標記，不會真正上傳；不支援生圖、生影片。引擎只提供 Chat Completions，其他介面由 Magpie 轉換。README 的 128K context 是供客戶端壓縮的宣告，不是經官方驗證的網站上限；標記費用為 0 不代表服務、訂閱或用量一定免費。
  • README 稱 cookie 存於引擎資料目錄的 accounts.json，另有 engine.key、engine.log 和瀏覽器設定。macOS 預設為 ~/Library/Application Support/muse-web；Windows 為 %APPDATA%\muse-web；Linux 為 $XDG_DATA_HOME/muse-web，預設 ~/.local/share/muse-web。作者稱檔案限當前使用者讀取、日誌不含對話與 cookie；這些是作者聲明，不是安全稽核。cookie 與 key 可攜帶帳號權限，勿分享、提交版本庫或送到第三方，清除前先確認實際路徑。
  • 網頁自動化、持續登入、多帳號與代理可能涉及服務條款、帳號停權、隱私及資料外洩風險；先查閱適用條款，不假設合規。外掛能接觸帳號與對話；模型產生的工具呼叫可能觸及本機檔案或執行命令，應啟用人工審批、最小權限，避免敏感資料。網站改版可使整合失效。
