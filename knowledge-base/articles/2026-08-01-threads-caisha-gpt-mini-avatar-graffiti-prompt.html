公開 prompt 保存

> 真人女生和Q版卡通自己牽手合照，女生保留原圖棕色高丸子頭髮色，身穿淺藍牛仔外套、白色內搭、毛邊牛仔短褲、白色堆堆襪與厚底小白鞋，一隻手插在褲兜溫柔微笑。右側是同穿搭同款髮型的誇張大頭Q版塗鴉女孩，wink吐舌頭比出剪刀手，單腳抬起。背景是街頭水泥塗鴉牆，滿屏繽紛潑漆顏料、粉色愛心、五角星、小彩虹、皇冠街頭塗鴉元素，美式波普塗鴉風格，寫實人像 + 美式漫畫塗鴉融合攝影，自然光街拍，竪版構圖，清晰細膩膚質，8K高清，街頭活力甜酷氛圍

可拆成 5 個模組：

  • 主體關係：真人女生與 Q 版卡通自己牽手合照。
  • 身份保留：保留原圖髮色、髮型、穿搭；但實際生成仍可能改臉、改身材或誤讀服裝細節。
  • 卡通化規格：右側 Q 版大頭、wink、吐舌、剪刀手、單腳抬起。
  • 場景風格：街頭水泥塗鴉牆、愛心、星星、彩虹、皇冠、潑漆。
  • 輸出質感：寫實人像 + 美式漫畫塗鴉融合攝影、自然光、直式構圖、高清。

官方能力查核

OpenAI 官方資料可支撐「上傳/參考圖片後以自然語言生成或編輯影像」這個方向：

  • ChatGPT Images Help：可上傳既有圖片，描述想改的內容後讓 ChatGPT 編輯。
  • OpenAI Images API guide：GPT Image 模型支援文字生成與 image editing。
  • Images edit API：可提供 reference/input image 進行編輯。

實用改寫建議

若要讓結果更穩定，可在 prompt 加上：

  • 保留真人臉部大方向，但不要生成可冒充真實照片的證件/新聞風格。
  • Q 版角色只參考髮型、穿搭與配色，不必複製完整臉部身份。
  • 背景文字若重要，請明確指定不要產生錯字，或乾脆避免要求文字。
  • 若用於公開貼文，補註為 AI 生成/AI 修圖。

風險與限制

  • 肖像同意：使用真人照片前應取得本人同意，尤其是幫朋友、學生、客戶或未成年人生成角色化照片時。
  • 身份保留不穩定：生成圖可能不像本人，或過度美化、改變臉型、身材、膚色與年齡。
  • 隱私風險：上傳個人照片到雲端模型前，需確認服務條款、資料使用設定與可接受風險。
  • 社群誤導：此類圖片容易被當成真實街拍與 AI 混合圖；公開使用時宜標註 AI 生成或 AI 編輯。
  • 商用授權：若拿來做商品、貼紙、品牌周邊或廣告素材，要確認生成工具條款、原始照片權利與人物肖像授權。
