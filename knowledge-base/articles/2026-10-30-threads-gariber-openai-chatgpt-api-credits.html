ChatGPT Pro／Business 可領 API credits｜資格、額度、綁定與不能拿來做什麼

Threads 作者 Gariber Zyo 分享：符合資格的 ChatGPT 訂閱者可在網頁版帳務設定中，將訂閱權益連到 API organization 領取 API credits；貼文以 Pro $200 tier 對應 $200 credit 為例。這項說法不是單純的社群傳聞：OpenAI Developers 已有專門的官方說明頁，明確列出 Pro 與 Business 的額度、資格與限制。

不過最重要的界線是：這是給 API Platform 的用量額度，不是 ChatGPT 對話額度，也不會增加已登入 Codex 的使用上限。

官方核對：哪些方案、可拿多少？

OpenAI 官方文件目前列出的每月 API credits（美元）如下：

  • Pro（$100 tier）：$100
  • Pro（$200 tier）：$200
  • Pro（$500 tier）：$500
  • Business Standard：每個付費席位 $20
  • Business Premium：每個付費席位 $100

Business credits 會匯總到工作區，但每月上限為 $500。年繳 Business 會一次取得該年度的 grant，並在年計費週期結束時到期。

領取資格：不是所有 ChatGPT 訂閱都有

依官方文件，要領取此權益，必須同時符合：

  • 持有至少滿 7 天的付費 ChatGPT Pro 或 Business 訂閱。
  • 免費試用與免費贈與／complimentary 訂閱不符合資格。
  • 是 ChatGPT 訂閱（或 Business workspace）的 owner，也同時是接收 credits 的 API organization owner。
  • ChatGPT 與 API 帳號須使用相同 email。

因此 Plus、Go、Free 與 Enterprise 不在這項權益的適用對象中；不能把「有付費 ChatGPT」概括理解成一定可領。

如何領取：ChatGPT 網頁版或 API Platform 都可以

官方提供兩條等效路徑，目標都是把符合資格的訂閱綁到一個你擁有的 API organization。

從 ChatGPT：

  • 以持有符合資格訂閱的帳號登入網頁版 ChatGPT。
  • Pro：開啟 Settings → Billing；Business：在 ChatGPT workspace billing settings 或 Admin Console 開啟帳務設定。
  • 尋找 API credits benefit 並開始領取流程。
  • 檢查／選擇要接收 credits 的 API organization。
  • 確認啟用；之後可到 API Platform 的 Billing settings 查看餘額。

可直接開啟的官方入口：

  • https://chatgpt.com/settings/billing
  • https://platform.openai.com/settings/organization/billing/overview

第一次核發會依目前計費週期剩餘時間按比例計算；啟用一次後，只要訂閱持續符合資格，會在訂閱續費時自動發放新的 credits。

到期與帳務：務必分開看

  • 當期未使用的 free credits 在計費週期結束時失效，不會 rollover。
  • 系統會先消耗 free credits，再消耗購買的 API credits。
  • 免費餘額與購買餘額皆為零時，API request 會收到 HTTP 429 與 `credit_balance_exhausted`。
  • 官方明示有有效 free credits 時，API 不必先設定付款方式；但若要不中斷地持續使用，仍可在 API organization 中加購 credits 或設定 Auto Recharge。

能用於什麼？不能用於什麼？

官方列出的涵蓋範圍包含 Responses API、Agents API（包括 OpenAI-hosted sandbox charges）、Decisions API、GPT-Live／Realtime API、Images API，以及 web search、file search、Code Interpreter 等 built-in tools 的用量與儲存費用。

但有一個容易誤會的例外：

用 API key 的 Codex usage 不適用這項 benefit。

官方也明確表示，這些 API credits 不會提高 ChatGPT 本身或已登入 Codex 的使用限制。若你的 Codex 是以 ChatGPT OAuth 登入，仍須依 ChatGPT／Codex 介面顯示的方案用量與限制判斷；不能把 API credits 視為其替代額度。

給 Hermes／Agent 使用者的實務判讀

這項權益適合拿來測試需 API key 的工作流，例如自建小型 agent、Responses API、圖片產生、語音／Realtime 或在 API Platform Playground 測 prompt。它不會自動注入 Hermes，也不會自動替 Hermes 的 provider 設定付款或 API key。

若要讓 Hermes 使用，仍應在自己選定的 API organization 建立 project API key，並依需求安全地設定到該 Hermes 主機的 `~/.hermes/.env`；不要把 API key 貼進聊天、技能檔、Git repository 或公開知識庫。先在 API Platform 的 Usage 與 Billing 介面確認組織、剩餘額度與 rate limits，再啟用可能產生大量 token／工具費用的自動化任務。

結論

這次不是「所有訂閱者都免費得到 API」的泛用優惠，而是 OpenAI 官方已文件化的 Pro／Business 訂閱權益：需符合方案、帳齡、owner 與同 email／organization 綁定條件。$200 Pro 對應 $200 的案例確實存在，但 credits 有當期到期、不累積、組織綁定與不適用 API-key Codex 的限制；領取前後都應以自己的 Billing 頁面為準。
